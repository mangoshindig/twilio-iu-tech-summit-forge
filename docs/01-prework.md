# Participant Prework Checklist

Complete before workshop day to avoid setup delays.

## Required installs
- Git
- Node.js 22.13 or later
- Python 3.10 or later
- ngrok
- One code editor

## Verify local tools
Run these commands:
- node --version
- npm --version
- python --version
- ngrok version

## Network and machine requirements
- Admin access on laptop
- Outbound HTTPS allowed
- Ability to run local web server and tunnel

## Accounts and credentials
Provided by facilitator per team in environment file:
- Twilio Account SID
- Twilio Auth Token
- Twilio API key SID and secret
- Team Twilio phone number or sender config
- Conversation Orchestrator service identifiers
- Conversation Memory service identifiers
- OpenAI API key
- Team spend cap value

## Team package contents
Each team should receive:
- One env file for TypeScript starter
- One env file for Python starter
- Team ID and demo slot number

## Day-of sanity check (5 minutes)
- Clone workshop repository
- Open team folder
- Start local server
- Confirm health endpoint responds
