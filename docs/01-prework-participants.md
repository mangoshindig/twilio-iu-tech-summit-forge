# Participant Prework Checklist

Complete before workshop day to avoid setup delays.

## Accounts needed
- Github
- Ngrok (free tier is fine)

## Required installs
- Git
- Node.js 22.13 or later (can use nvm) OR Python 3.10 or later
- ngrok
- One code editor

## Verify local tools
Run these commands:
- node --version && npm --version OR python3 --version && pip3 --version
- ngrok version

## Network and machine requirements
- Admin access on laptop
- Outbound HTTPS allowed
- Ability to run local web server and tunnel

## Optional
- Vibe coding agent (e.g. Claude Code, Github Copilot)
